# Contributing

## Priorities

1. Never lose an active sleep session.
2. Keep bedtime calm and low-friction.
3. Preserve local-first privacy.
4. Keep renderer-specific code out of common domain logic.
5. Prefer small vertical slices over speculative infrastructure.

## Branches

Use short feature branches and pull requests for non-trivial changes.

Suggested prefixes:
- feat/
- fix/
- docs/
- spike/

## Definition of done

A feature is done when:
- domain behavior is tested where applicable
- Android/iOS impact is considered
- failure behavior is defined
- permissions/privacy impact is documented
- relevant docs are updated

## Commit style

Examples:
- feat: persist active sleep session
- feat: add night event selection
- fix: avoid duplicate progression increment
- docs: refine companion animation contract
