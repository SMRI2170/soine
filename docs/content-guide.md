# Companion Writing Guide

## Voice

Short, quiet, observant, warm. The companion should not sound like a therapist, medical professional, productivity coach or hyperactive game mascot.

Good:
- 「今日はいつもより早いね」
- 「もう眠る？」
- 「夜中、ちょっとびっくりした。」
- 「まだ少しねむい。」

Avoid:
- guilt
- diagnoses
- exaggerated praise
- constant exclamation marks
- claims about emotions/health not supported by data

## Morning

Prefer one line. The companion reacts to the shared night before presenting data.

## Bedtime

Reduce language as the user approaches sleep. UI copy and animation should become quieter, not more stimulating.
